# v2 方案 A（独立完成，没有参考方案 B）

## 风格：奶油奇趣风（Cream Whimsy）＋一点多巴胺糖果色
- 依据：小红书《2026 年度居住趋势》"适我主义"，奶油风搜索热度下降，年轻人改成按自己的兴趣来布置（痛屋、精神领地等）[SocialBeta 2026-04]；
  租房改造现在流行"奶油奇趣"：奶白、浅粉打底，加圆润软家具、点点或棋盘格地毯、玩偶、趣味摆件 [网易 2026-04 / 什么值得买 2026-08]；
  2025 多巴胺风格：圆润软家具、蘑菇灯/波浪灯这类"快乐灯"、图案地毯 [Searchome 2025-05]。
- 不用老气的胡桃木和中古：改用奶白＋糖果色、圆角/波浪/泡泡造型、bouclé、亚克力。
- 配色：奶油白 #FFF6EA（大面）/ 草莓奶昔粉 #F6B8C8 / 抹茶奶绿 #BFD8A6 / 柠檬黄 #FFE07A / 天空蓝 #A8D4F0 / 可可棕 #7A5543（少量压色）

## 布局（全部落地/台面，不碰墙和天花）
- 床 140×200 双人（ダブル），带储物抽屉，云朵/涟漪软包床架，长边贴西墙，床头朝南：x0–144, z88–296。一个人睡很宽，两个人也够。
- 北墙西段 x0–135 白墙 = 投影幕（60–65 寸），不挂任何东西。投影仪放在床头旁的推车上往北投，人在床上打 PS / 看剧。
- 北墙下：低柜 120×35×45（收 PS 游戏碟、手柄、杂物），比投影画面底边低。
- 东墙：伸缩桌（一个人 120×70 → 两个人拉长到 160×70），x245–315。吃饭、电脑、化妆三用；显示器用支臂，吃饭时推到一边。
  一个人时桌子在 z133–253，衣柜前空出很大一片；两个人时拉到 z93–253，衣柜折门前（z60–90）一直空着。
- 桌下正中带轮双层架：主机＋路由器。
- 床头旁三层推车 = 床头柜＋投影仪＋PS5 的位置。
- 自立式波浪全身镜靠西墙北段（地上立着，不固定）。
- 灯：波浪落地灯（桌边）、彩色蘑菇台灯（推车上）。原来的吸顶灯不动。
- 地毯：棋盘格 / 波浪边地毯 120×160，在床和桌之间。
- 主通道：床 ↔ 桌约 100cm。门扫区、衣柜折门前 30cm 全空。

## 一人 → 两人
桌子从 120 拉长到 160；加第二把椅子（可叠放的蘑菇凳，平时塞在桌下）；加第二床被子和枕头；低柜旁再加一个同款储物单元。床不用换。
