# v3 布局试验：L 型桌放原床位

用户要求：床还是原来那张 140×195；桌子换 L 型，L 角在左边（西）；主桌 160×70 靠西墙，副桌 50×120 靠床。

## 坐标（原点在西北角，x 往东，z 往南，单位 cm）
- 主桌 x0–70、z0–160；副桌 x70–190、z110–160（L 角在主桌南端）。
- 床框 199×145（低床，床面高 42）：x0–199、z161–306，床头朝西。和 index.html 原来的床位一样（原来是 x0–195、z168–308）。
- 东墙：落地灯 z92–120；矮柜 100×35×45 在 x280–315、z130–230，上面放超短焦投影和 PS5；投影画面在东墙 z120–240，约 54 寸。
- 北墙：全身镜 x80–125；门 x143–227；衣柜 x250–315。
- 桌下：主机架在主桌下 x15–65、z10–40；推车和蘑菇凳收在副桌下面。

## L 角为什么放在南端
放在北端的话，副桌要沿北墙伸到 x190，会撞进门扫区（x143–227），而且离床很远。放在南端，副桌刚好贴着床，所以选南端。北端的方案只写在页面里，没有做 3D。

## 净空和通道
- 门扫区：里面是空的。离得最近的是两人模式下的凳子（中心在 150,90），还隔约 15cm。
- 衣柜折门前 z60–90：一直空着。
- 门 → 副桌东端/矮柜之间：90–96cm。
- 床尾 → 矮柜：81cm。
- 去阳台：床尾到柱子 / 可开窗扇之间只有 54–56cm，这是全屋最窄的地方。
- 主桌椅子往后拉：桌边到门扫区边缘 119cm；椅背后面 65cm。
- 副桌座位往后拉：约 75cm 后碰到门扫区边缘。
- 上下床：只能从东边床尾上下，北边是副桌，南边是窗户。

## 冲突和最小改法
1. 主桌 160 加床框 145 是 305，房间深 308，只剩约 2cm。床框必须是薄边、无厚床头的款。
2. 去阳台 54cm。换 197 长的床框能多 2cm；想明显变宽，只能换 120 宽的床。
3. 只能从床尾上下床。把副桌缩到 90 长，床北侧东段会空出约 40cm。
4. 床贴着落地窗，窗帘下摆会被床压住。建议换成短帘（到床面高度）。
5. 两人住时收纳偏少，这一点没有解决。
