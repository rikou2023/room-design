# 东京出租屋卧室 v2：奶油多巴胺奇趣风

## 1. 风格：奶油多巴胺奇趣风

上一版中古风偏暗偏棕，所以显得老气。这一版把中古的软体保留下来，打底改成奶油白，再用 2–3 块高饱和糖果色做点缀，家具多用波浪边、蘑菇、云朵这类造型，地上铺棋盘格地毯。2025–26 年小红书和抖音上租房改造热度很高的两个标签，"奶油奇趣风"和"多巴胺小屋"，就是这个组合。它适合 3m×3m 的小房间，原因有三：
- 浅底色加矮家具，一个人住时房间显得宽敞。
- 有趣的地方都在可以搬走的物件上，不碰墙，也拍得出照片。
- 加一点电竞元素（桌面 RGB 灯条、云朵电竞椅），游戏需求也照顾到了。

## 3. 布局

- **西墙**：沙发床靠墙放，x0–100，z85–285，床尾离窗 23cm，留给窗帘收拢。
- **东墙**：一张 155cm 长的波浪边大桌，x255–315，z95–250。北端离开衣柜折门前的净空区（z60–90），南端离开柱子（z253 起）。
- **西北角**：云朵书架和波浪全身镜，都在门扫区（x143 起）以西。
- **中间**：可升降的圆茶几，下面铺棋盘格地毯。
- **关键净距**：茶几东沿（x170）到椅子推进去后的椅背（x235）有 65cm，这就是主通道，从门直通落地窗可开扇。可开扇 x129–253 前面不放任何东西。

**一人模式（白天）**：沙发床收起只有 100cm 宽，地面中间留出大约 155×200cm 的空地。

**两人模式（夜里）**：拉出子母床的下层并弹起，拼成 190×200 的双人床。茶几推到书桌南端（x190–250，z200–260）。床边到桌子还剩约 45cm，夜里够走。女朋友搬来以后，把云朵书架换成同位置的布艺衣柜，再加一把折叠凳。

## 4. 功能怎么解决

- **吃饭**：茶几从 45cm 升到 68cm，一个人坐沙发床边吃，两个人再加一把亚克力凳。
- **PS 大屏**：显示器选 32" 4K 144Hz，装在夹桌式悬臂上。悬臂整体旋转 180° 后屏幕朝西，人窝在沙发床上，离屏约 1.6m。电脑和 PS 共用这一块屏。
- **电脑**：坐在桌子中段。主机放在桌下南端的滚轮托架上，路由器放在主机顶上。
- **化妆**：桌子南端放翻盖式化妆镜收纳盒，配全身镜。
- **睡觉**：平时睡沙发床，100cm 宽。两人时睡 190cm 宽的双人床。

## 6. 最出彩的 3 点与风险

**出彩**
1. 一块悬臂屏转个身就从电脑屏变成床上的游戏屏。
2. 一张沙发床白天当沙发，夜里展开成双人床。
3. 整套方案不打一个孔，有趣的东西全是落地或台面上的物件，退租时直接搬走。

**风险**
- 32" 显示器当作游戏"大屏"，效果比不上电视，后期可以加一台放在地上的投影仪，投到北墙上。
- 子母床每天拉出、收回比较麻烦，选购时要买气压弹起款。
- 两人模式下通道只有 45cm，只在夜里用。
- 颜色要守住"大面积奶油白、彩色不超过 20%"，彩色一多房间就会显得乱、显得挤。
